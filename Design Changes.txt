The Last Elevator
Changes from the Original Design Document
Parleen Kaur

The finished game keeps the main idea from my one-pager: the player starts inside an elevator, visits three strange floors, solves a puzzle on each floor, and tries to escape. Some parts changed while I was building and testing the game.

1. Floor 1 became a word scramble puzzle

The one-pager described a room filled with clocks but did not decide on the exact puzzle. In the finished game, the player solves three scrambled words using riddles. Every correct word starts one clock. Solving all three unlocks the elevator door. I chose this because it made the clock room more interactive and gave the player clear progress.

2. Floor 2 became a memory pattern puzzle

The upside-down office stayed in the game, but its puzzle changed. Six office objects appear upside down. The game flashes a random sequence and the player must click the same objects in order. There are three rounds with patterns of two, three, and four objects. The pattern starts automatically, and R can replay it. This was more interesting than using one fixed object sequence.

3. Floor 3 changed completely

The one-pager planned an empty hallway where objects changed whenever the player looked away. The finished Floor 3 is a spot-the-difference puzzle called Fractured Memories. The player compares an original archive room picture with an altered picture and clicks three missing objects in the original. I changed this because the picture puzzle was easier to understand, test, and finish within the project scope.

4. The game has one ending instead of three

The original design planned three endings based on player choices: escaping, becoming trapped, or discovering that the floors were memories. The finished game has one main goal. Completing Floor 3 shows an escape successful message. Until the puzzle is complete, the player is still trapped and can start again. I removed the other endings so I could spend more time making the three puzzles work reliably.

5. Dialogue choices and risky decisions were removed

The original game flow included choices about continuing, returning, and trusting the elevator. These choices and the dialogue choice interface were removed. The final game follows a clear order from Floor 1 to Floor 3. The player still returns to the elevator after each puzzle, but the next floor is selected automatically by the glowing button.

6. Some controls changed

The elevator and Floor 1 use A/D or the left and right arrow keys for movement. E, W, Up, or Space can interact with nearby objects. Floor 2 allows movement in all four directions using WASD or the arrow keys, and its objects can also be clicked with the mouse. Floor 3 is controlled mainly with the mouse. It supports zooming, panning, hints, and clicking differences.

7. The pause menu was not completed

The one-pager listed Esc as a pause control. A full pause menu was not added. Esc is used to close the Floor 1 word puzzle and return to the room. Restart controls are available at the end of the game.

8. The character and animations were simplified

The finished game uses a small explorer character. The character turns left and right, has a small walking bounce, and has an idle breathing effect. I did not add a full frame-by-frame walking animation or an NPC/shadow character. Elevator movement, door movement, flashing lights, puzzle highlights, and object flashes provide the other animations.

9. The art style became a mixture of shapes and detailed images

The elevator and room structures use simple dark-colored shapes as planned. The upside-down office uses detailed images for the key, table, pen, chair, notebook, and lamp. Floor 3 uses two detailed archive room pictures. Each floor still has its own color and visual style.

10. Sound was created directly in the project

The game includes footsteps, elevator movement, button sounds, a bell, sliding doors, clock ticks, electrical ambience, interaction sounds, and success and failure feedback. These sounds are generated by the game code instead of being stored as separate audio files. I kept the original plan of having no constant background music.

These changes helped keep the project small enough to finish while still keeping the original elevator theme, three puzzle floors, exploration, sound effects, and final escape goal.
