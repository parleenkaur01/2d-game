# The Last Elevator

Unity 2D prototype for the individual 2D game project.

## Current vertical slice

The playable slice starts inside the elevator. Examine the warning on the left, press the glowing button on the right, and ride to **Floor 1: The Clock Room**. Read the note on the left wall, set the labeled clocks in order `III, I, II`, then use the unlocked elevator door. Back in the elevator, press `R` to replay the slice.

Controls:

- `A/D` or left/right arrows: move
- `E`, `W`, up arrow, or space: interact
- `R`: replay after finishing Floor 1

## Running it

1. Open this folder as a Unity 2D project.
2. Open `Assets/Scenes/Main.unity`.
3. Press Play and click inside the Game window to give it keyboard focus. The prototype builds its rooms at runtime.

The visuals and simple sound effects are generated in code for the first milestone. Authored art, additional floors, pause controls, and the three final endings will follow in later milestones.
