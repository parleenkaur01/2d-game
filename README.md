# The Last Elevator

Unity 2D prototype for the individual 2D game project.

## Current vertical slice

The first playable slice is **Floor 1: The Clock Room**. Move through the room, read the clue, activate the clocks in order `III, I, II`, and return to the elevator door.

Controls:

- `A/D` or left/right arrows: move
- `E`, `W`, up arrow, or space: interact
- `Esc`: reserved for pause flow

## Running it

1. Open this folder as a Unity 2D project.
2. Open `Assets/Scenes/Main.unity`.
3. Press Play. The current prototype builds its placeholder room at runtime.

The visuals are intentionally code-generated for the first milestone. Authored art, audio, additional floors, and the three final endings will replace the placeholders in later milestones.
